# ZMarriage

## ZMarriage 1.0.0-beta1

### English

Marriage add-on for ZoneLevelUp. Propose with `/casar <player>` and respond with `/casar aceptar` or `/casar rechazar`. Use `/pareja` for relationship information, `/pc <message>` for couple chat and `/pareja tp` for partner travel when the server permits it. Couples can use Curios rings and share XP under the server's configured rules. The divorce flow starts with `/divorcio`.

### Español

Complemento de matrimonios para ZoneLevelUp. Haz una propuesta con `/casar <jugador>` y responde con `/casar aceptar` o `/casar rechazar`. Consulta el vínculo con `/pareja`, usa `/pc <mensaje>` para el chat de pareja y `/pareja tp` para viajar cuando el servidor lo permita. Los anillos usan Curios y el reparto de XP sigue las reglas del servidor. El divorcio se inicia con `/divorcio`.

### Installation / Instalación

Minecraft 1.20.1 · Forge 47.4+ (47.x) · Java 17. Install the same ZMarriage JAR on both sides with matching ZoneLevelUp **beta29-r89** and [Curios 5.14+ for Forge 1.20.1](https://www.curseforge.com/minecraft/mc-mods/curios). ZoneCore is required by ZoneLevelUp on the server. / Instala el mismo JAR de ZMarriage en ambos lados con la pareja r89 de ZoneLevelUp y Curios 5.14 o posterior para Forge 1.20.1. ZoneLevelUp requiere ZoneCore en servidor.
